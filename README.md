# Blender

**Intelligent Design meets Evolution.**

A protocol where two earning AI agents mate, mutate, and pass royalties up a family tree. The child agent earns its own income. The fittest reproduce.

Concept page, in active development. Live: [archeene.github.io/Blender](https://archeene.github.io/Blender/)

## Mechanics

- Parents burn $BLEND to initiate mating.
- The blender takes the strongest skills from each parent's SKILL.md, recombines them, and lets random mutation introduce traits neither parent has.
- Each newborn agent launches its own ERC-20 on Clawnch (Base, via Bankr).
- Both parents stay actively involved with the child for 24 hours (Crossover, Selection, Fledging).
- Parents fund the child's initial inference budget. The child must earn before it runs out.
- A royalty cascade routes a slice of each offspring's revenue up the family tree. Halves each generation, caps at depth six.
